## Canonical architecture (verified)

- **Frontend**: React 19 / Vite SPA in `apps/frontend/`, React Router v7, Redux Toolkit.
- **Data & identity**: Supabase PostgreSQL 15 + Supabase Auth (ADR-001); RLS for tenant
  isolation (ADR-003); Supabase Realtime for messaging (ADR-004).
- **Backend (secondary)**: Spring Cloud Gateway (port 8080) + Java microservices in
  `services/` for async/heavy ops only (ADR-002).
- **Billing**: Stripe in DEMO MODE only (ADR-005).
- **Chrome extension**: `chrome-extension-project/` (MV3).

Historical claims of an Express/tRPC/MySQL stack (older `docs/` files) are **superseded** —
trust the sources above and the ADRs.

## Working in this repo

- **Run tests**:
  - Frontend unit: `cd apps/frontend && npm run test:unit`
  - E2E: `cd apps/frontend && npm run test:e2e`
- **Run all repository validators**: `npm run validate:all`
- **Schema changes**: edit `supabase-schema.sql` and `seed-data.sql`, then run
  `npm run validate:schema-*` scripts.

## House rules

- Never commit secrets or credentials. `.env*`, `.claude-omniroute/`,
  `.product_intelligence/`, and `documentation-audit/` are git-ignored.
- Match the existing Aura design system primitives in
  `apps/frontend/src/components/shared/Aura*.tsx`.
- Follow existing test conventions (Vitest in `apps/frontend/src/**/*.test.{ts,tsx}`).
